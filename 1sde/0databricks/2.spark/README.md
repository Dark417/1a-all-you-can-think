# PySpark Local Tutorial — US Housing Market Data

A self-contained PySpark playground for Windows. Everything Spark needs (JDK, winutils,
JDBC driver, Python env) lives inside this folder — nothing depends on system installs.

## Quick start

```
start_jupyter.cmd
```

Then open `spark_tutorial.ipynb` and run top to bottom. While a session is alive, the
Spark UI is at <http://localhost:4040>.

## What's in the notebook

14 sections covering the common Spark surface:

| Sections | Topics |
|---|---|
| 0–2 | SparkSession config, reading CSV (inferred vs explicit `StructType` schema), inspection (`show`, `summary`, `toPandas`) |
| 3–5 | select / filter / `withColumn` / `when-otherwise`, string & date & math functions, null handling and cleaning |
| 6–8 | `groupBy` aggregations, `approx_percentile`, `pivot`, joins (broadcast / semi / anti), window functions (`row_number`, `lag`, rolling averages) |
| 9–11 | Spark SQL temp views, UDFs vs pandas UDFs, `explain()`, `cache()`, `repartition` vs `coalesce` |
| 12 | Writing Parquet (with `partitionBy`), CSV, JSON, partition pruning |
| 13 | **SQLite round-trip**: write via JDBC → read back → update (Spark overwrite pattern *and* raw `sqlite3` UPDATE) → save back to Parquet |

## The dataset

`data/housing_sales.csv` — 50,000 US home sales (2021–2024) across 30 cities: price,
beds/baths, sqft, property type, year built, HOA, sale date, with deliberate nulls for the
cleaning section. `data/city_stats.csv` — per-city median income + population for joins.

Generated by `generate_data.py` (seeded, reproducible, calibrated to plausible market
numbers). Regenerate with `.venv\Scripts\python.exe generate_data.py`.

**Want real data instead?** Drop-in options:
- [Zillow Research data](https://www.zillow.com/research/data/) — ZHVI home values, direct
  CSV downloads, no signup. Wide format (one column per month) — good `melt`/unpivot practice.
- [Kaggle: King County house sales](https://www.kaggle.com/datasets/harlfoxem/housesalesprediction) —
  21k Seattle-area sales, very similar schema to ours.
- [Redfin Data Center](https://www.redfin.com/news/data-center/) — market tracker TSVs.

## Windows gotchas this setup already solves

These three bit us during setup — the notebook's first cell handles all of them:

1. **Broken system `JAVA_HOME`** — `C:\Program Files\Java\jdk-17` exists on this machine but
   is empty (no `java.exe`), which makes PySpark *hang forever* waiting for the JVM gateway.
   Fix: project-local JDK in `jdk/`, `JAVA_HOME` set in-notebook.
2. **Wrong worker Python** — Spark launches workers with `python3` from PATH (here Python
   3.14, unsupported by PySpark 3.5) → `WinError 10038` socket crashes mid-job. Fix:
   `PYSPARK_PYTHON` pinned to the venv interpreter.
3. **File writes fail without winutils** — any `df.write` on Windows needs `winutils.exe` +
   `hadoop.dll` and `HADOOP_HOME`. Fix: bundled in `hadoop/bin/`.
